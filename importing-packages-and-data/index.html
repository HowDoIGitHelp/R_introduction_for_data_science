Importing Packages

Packages are collections of libraries that contain helpful code that you can use for your own projects. It can contain helper functions, new classes, and more. Some of these packages come preloaded in R while some of them must be manually loaded. For example the class package, which contains basic classification models do not come preloaded in R. To load packages like these, you need to use the library function.

library(class)

To view all of the installed packages in your system you can use the following function:

head(installed.packages())
Loading...

If you want to use external packages that are available in repositories like CRAN you can use the following function:

install.packages("ggplot2")

You only need to install a package once, but you need to import packages anytime you need them. To remove uninstall packages in your system you can use the following function:

Some helpful external packages for data science¶

  • dbi - connects R with your various database management systems

  • tidyverse - includes a collection of packages for data science, including visualization (ggplot2), data manipulation (dplyr), data cleaning (tidyr) and more.

  • rmarkdown - create notebooks that combine markdown with R code

Importing data¶

To import actual datasets in R, you can use the function below. This will store the contents the csv into a dataframe.

dataset <- read.csv("dirty_cafe_sales.csv")

To export a dataframe into an external csv file you can use the following:

write.csv(dataset, "backup.csv", row.names = FALSE)

The argument row.names = FALSE, prevents R from including the autogenerated row indices from importing
