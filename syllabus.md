# Introduction to Programming for Data Science

**Course Title**: Introduction to Programming for Data Science

**Course Description**: Basic programming concepts for Data Science.

**Number of Hours**: 6 hours per week for 4 weeks.

# Course Goals

This course aims to provide students with prerequisite skills to use Data Science software. At the end of this course students will be able to: apply programming techniques to model data, solve simple problems using basic programming concepts, create small automation scripts to process simple datasets. The course will use both R and Python to demonstrate and apply programming concepts.

# **Course Outline**

## Programming Basics in R

1. R Workspace
    a. Expressions
    b. Simple Types
        i. Numerical Types
        ii. Characters
        iii. Logical
        iv. Datetime
    c. R Objects
2. More R Datatypes
    a. Vectors
        i. Element wise operations
    b. Matrices and Arrays
    c. List
    d. Data Frames
3. Functions
    a. Using Functions
    b. Creating Functions
4. R Scripting
    a. Loops
    b. Vectorized operations
5. Statistical Computing
    a. Charts
    b. Statistical tests
    c. Statistical modelling
6. R Packages
    a. Using R-Packages
    b. Installing and updating packages

## Programming Basics in Python

1. Python Expressions
    a. Expressions
    b. Assignment Statements and Variables
2. Python Datatypes
    a. Numerical Types
    b. Booleans
    c. Lists and Tuples
    d. Strings
    e. Dictionaries
3. Python Scripts
    a. Creating python scripts
    b. Executing python scripts
4. Conditionals and Loops
    a. `if`-`else`
    b. `elif`
    c. `while` loops
    d. `for` loops
5. Functions
    a. Invoking functions
    b. Creating functions
    c. Anonymous functions

## More Software for Data Science

1. Data Analytics
2. Visualization and Presentation
3. Prediction and Machine Learning
4. Data Warehousing and Big Data
